Sobre Mí

Soy Licenciado en Gestión de Tecnología (UNLaM) y Técnico en Programación (UNLZ), con un perfil híbrido que integra el desarrollo de software con una visión estratégica del negocio.

Me especializo en el desarrollo Fullstack & Java Backend, utilizando Spring Boot (APIs REST, microservicios, Spring Security y JWT) y Angular (v19+) (Signals, Standalone Components, arquitectura Zoneless y RxJS). Complemento la arquitectura con contenerización en Docker y automatización de pipelines mediante CI/CD con GitHub Actions.

Desempeñé el rol de líder de desarrollo backend en un proyecto de tesis en equipo bajo Scrum, donde modelé y diseñé la base de datos relacional, construí la lógica de negocio completa de la aplicación y participé en la documentación funcional (Story Mapping, Product Backlog y criterios BDD).

Con enfoque en Calidad de Software (QA Técnico), diseño y ejecuto pruebas unitarias y de integración utilizando JUnit 5, Mockito y MockMvc para asegurar un código robusto, limpio y mantenible desde la base.
